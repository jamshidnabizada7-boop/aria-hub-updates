# ARIA HUB — Reference 09 (ad-only)

Ninth isolated ARIA HUB motion recreation.

## Focus rule

Only the actual advertisement is recreated. These elements are intentionally excluded:

- `@DAKSH.VFX`
- Instagram logo/watermark
- creator outro
- any social/creator branding outside the product-ad language

## Advertising structure preserved

The reference uses a compact AI-product demo structure:

1. brand reveal
2. glowing request/prompt object
3. typed instruction
4. generated result
5. quick editing/action controls
6. portrait/mobile transformation
7. speed/productivity claim

ARIA HUB translates that directly into opportunity search, a matched result, fast actions, mobile access and a clear final CTA.

## Typography

- **Noto Kufi Arabic Variable** — Persian advertising headlines
- **Vazirmatn Variable** — UI and supporting Persian copy

## Audio

The downloadable source package contains `public/audio/reference-09-ad-original.m4a`, extracted from the supplied reference and trimmed to the 13.5-second ad-only section.

For GitHub checkouts, regenerate it with the included script.

## Run

```bash
cd video-studio-reference-09
npm install
npm run studio
npm run render
```

4K:

```bash
npm run render:4k
```
