# ARIA HUB — Reference 05

Fifth fully isolated ARIA HUB motion recreation based on the uploaded **11.2-second** minimal dark-interface reference.

## Isolation

This project is independent from References 01–04. It has its own package, composition, components, copy, and render commands.

## Visual system

- black / near-black cinematic canvas
- warm coral / amber glow adapted to ARIA HUB
- high-speed prompt UI zooms
- animated typing and cursor behavior
- concentric submit-button impact
- short recommendation-list reveal
- ultra-minimal two-beat brand close
- ARIA HUB SVG kept vector-sharp

## Persian typography

- **Noto Kufi Arabic Variable** for cinematic Persian display headings
- **Vazirmatn Variable** for Persian UI, prompts and response text

## Audio note

The supplied Reference 05 MP4 contains **no audio stream**. Therefore this recreation does not falsely substitute another soundtrack. It is silent by default and ready for a separate sound-design layer if desired.

## Run

```bash
cd video-studio-reference-05
npm install
npm run studio
npm run render
```

4K:

```bash
npm run render:4k
```
