# ARIA HUB — Reference 11 (ad-only)

Eleventh fully isolated ARIA HUB motion recreation.

## Focus rule

This reference is already a motion-design advertisement, so there is no desk/monitor environment to remove. Instead, Reference 11 keeps only the **advertising grammar** and removes the original studio/social identity:

- Sandy Design Studio logo/name
- Instagram icons
- @SANDYDESIGNSTUDIO_ handle
- creator/social outro

## Advertising structure preserved

1. philosophical hook
2. kinetic symbol/play sequence
3. service/category cascade
4. portfolio-card showcase
5. abstract logo construction
6. final brand lockup

ARIA HUB translates that into opportunity discovery and opportunity categories.

## Visual style

- deep luminous cobalt/ARIA navy motion field
- restrained ARIA gold accent
- clean kinetic typography
- icon/category play
- dimensional opportunity cards
- procedural logo-build moment
- premium Persian RTL typography

## Typography

- **Noto Kufi Arabic Variable** — Persian display/advertising type
- **Vazirmatn Variable** — supporting/UI Persian
