# ARIA HUB — Reference 10 (ad-only)

A tenth fully isolated ARIA HUB Remotion recreation.

## What is ignored

The upload is a recording of a monitor in an editing setup. This project does **not** recreate:

- the person at the desk
- editing software
- monitor bezel
- keyboard / mouse / desk
- room lighting
- `pov: you make the cleanest ads`
- any creator/social context

Only the **clean ad displayed on the monitor** is used as creative reference.

## Advertising structure preserved

The plant-care reference uses a very efficient product-ad structure:

1. relatable repeated-problem hook
2. simple promise
3. visual problem state
4. analyze action
5. scanning / diagnosis
6. structured result dashboard
7. transformed success state
8. short tagline + brand finish

ARIA HUB maps this to missed opportunities, opportunity analysis, matching, deadlines, eligibility and next-step guidance.

- **Vazirmatn Variable** — Persian UI and supporting copy
