# ARIA HUB — Reference 12 (ad-language extraction)

Reference 12 is intentionally different from the earlier recreations because the uploaded source is an **88-second motion-design/showreel**, not a single coherent advertisement.

## Focus rule

Only the useful **advertising motion language** is extracted.

Not recreated:
- Instagram watermark / handle
- creator identity
- portfolio/showreel framing
- unrelated cartoon/game client scenes
- external brands
- the 88-second reel sequence itself

## Advertising language borrowed

- game-like kinetic pacing
- floating category/product objects
- neon/cyan/purple transitions
- bright product cards
- UI/scan moments
- fast visual reward/result reveal
- short kinetic CTA beats
- clean brand finish

## ARIA HUB result

A standalone **18-second** commercial about discovering and acting on opportunities.

Typography:
- **Noto Kufi Arabic Variable** — Persian ad headlines
- **Vazirmatn Variable** — UI/supporting Persian

Output:
