# ARIA HUB Reference 12 — ad-only interpretation

Uploaded reference metadata: **88.100 s · 720×400 · 30 fps · H.264 + AAC stereo (44.1 kHz)**.

Reference 12 is not one continuous product ad. It is a long motion-design/showreel containing many short advertising-style scenes, character spots, 2D/3D transitions, UI moments, game-like reveals and persistent creator/Instagram branding.

The ARIA HUB production therefore does **not** recreate the 88-second showreel. It extracts the strongest advertising motion language and rebuilds it as one focused **18-second ARIA HUB commercial**.

Production master: **18.0 s · 540 frames · 30 fps · 1920×1080 / 3840×2160**.
