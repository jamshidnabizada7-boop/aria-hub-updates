# Day 12 — Ambassador pilot playbook (internal ops)

Public page: `/en/ambassador` (built this pass — program, do/don't lists,
tracking, code of conduct, apply CTA). This file is the owner's operating side.

## Pilot size & gates

- Start: **10–20 ambassadors**, controlled pilot. Expand only after activity and quality are measurable.
- Quality gate: continue only ambassadors who create qualified traffic or useful community outcomes; remove spammy activity quickly (one warning, then out).

## Recruitment — first 10 candidates (owner action)

Sources, in order:
1. Users who already save/share opportunities (ask via Telegram/WhatsApp channels).
2. Success-story submitters (with permission).
3. The 5 P0/P1 education partners from Wave A/B — ask each for 1–2 names.
4. Diaspora student associations (U Toronto ASA, York — rows 49–50 of the CRM).

Recruitment message: the "ARIA HUB Campus / Community Ambassador — pilot cohort" text is on `/en/ambassador`; send it verbatim plus one personal sentence per candidate. Applications: email info@myariahub.com subject "Ambassador pilot".

## Tracking (per ambassador)

1. Assign a unique link: `https://www.myariahub.com/en?utm_source=amb-<name>&utm_medium=ambassador&utm_campaign=ambassador_pilot_2026q4`.
2. Keep a monthly activity log (sheet tab or the CRM `Result` column): sessions from their link, subscribers, event held, feedback items, guide published.
3. Monthly review: keep contributors, rotate out inactive/spammy ones.

## Recognition ladder

- Contribution-based certificate (after 2 productive months).
- Public profile on ARIA HUB (name + city + contribution summary, with consent).
- Recommendation letters based on real work.
- Event speaking opportunities.

## Non-negotiables (mirrors the public code of conduct)

No mass-DMs, no same-link-everywhere, no admission/visa/job guarantees, no
invented metrics, no impersonating staff, consent before sharing anyone's
story, official application links always intact.

## First campus/community activation (checklist)

1. Choose one campus/community with a warm route.
2. 35-minute session: "How to verify opportunities, avoid misleading links and build a deadline system."
3. Teach the method first; demonstrate ARIA HUB only after.
4. QR code with the ambassador's unique UTM link to a curated landing page (not the generic homepage).
5. One clear next action: join the weekly digest or save a filtered opportunity page.
6. Measure registrations, attendance, QR visits, subscriptions and repeat visits after 7 days.
