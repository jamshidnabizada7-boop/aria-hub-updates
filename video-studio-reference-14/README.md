# ARIA HUB — Reference 14 (ad-only)

Fourteenth fully isolated ARIA HUB motion recreation.

## Focus rule

Only the actual **Pinterest-style advertisement** is recreated. The creator/social layer after the ad is intentionally removed:

- Instagram outro
- large Instagram logo animation
- `@RONCREATESS` handle
- creator-specific watermark/social promotion

## Advertising structure preserved

1. very short curiosity question
2. large “Introducing” style brand reveal
3. isolated brand icon
4. visual discovery collage
5. reduction from many options to a focused result
6. concise branded closing line

## ARIA HUB adaptation

The “inspiration discovery” metaphor becomes “opportunity discovery”: multiple scholarships, jobs, internships and fellowships collapse into a focused result and ARIA HUB CTA.

Typography:
- **Noto Kufi Arabic Variable** — Persian advertising/display text
- **Vazirmatn Variable** — UI/supporting Persian

Output:
- 1920×1080 / 30 fps
- 3840×2160 / 30 fps
- 6 seconds / 180 frames
