# ARIA HUB — Reference 13 (ad-only)

Thirteenth fully isolated ARIA HUB motion recreation.

## Focus rule

This source is already a brand-ident advertisement. Reference 13 therefore keeps the **commercial motion language** while removing the original creator/social identity:

- no Instagram icon
- no @THECREATORSTUDIOO handle
- no The Creators Studio wordmark
- no creator/social CTA

## Advertising language preserved

- minimal high-contrast opening
- black projector/light-source object
- sweeping blue/purple beam wipes
- bold wordmark construction
- directional text reveals
- hard white-to-dark transitions
- concise brand ending

## ARIA HUB adaptation

The projector/light-beam metaphor becomes a search/discovery metaphor for ARIA HUB. The beam reveals the ARIA HUB identity, opportunity categories, website, and final CTA.

Typography:
- **Noto Kufi Arabic Variable** — Persian headline/display
- **Vazirmatn Variable** — supporting/UI Persian

Output:
- 1920×1080, 30 fps
- 3840×2160, 30 fps
- 15 seconds / 450 frames

## Audio

The source is itself the ad, so the package contains the original soundtrack trimmed to 15 seconds:

`public/audio/reference-13-ad-original.m4a`

cd video-studio-reference-13
npm install
