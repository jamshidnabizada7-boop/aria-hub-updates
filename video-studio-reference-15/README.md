## Deliverables

The downloadable package contains a rendered **1920×1080 / 30 fps / 17.0 s** H.264 master, the ad-only AAC soundtrack, QC/contact sheets, the deterministic renderer used for the delivered MP4, editable Remotion source, and an optional Blender smartphone-scene scaffold.

GitHub intentionally contains source only; binary audio/video are not committed. Regenerate the soundtrack with `scripts/extract-reference-audio.sh`.
