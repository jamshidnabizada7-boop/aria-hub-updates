# ARIA HUB Reference 06 — ad copy

This version deliberately recreates only the **advertisement shown on the monitor**. It does not reproduce the phone-recording environment, desk, monitor bezel, iPad storyboard, POV overlay, room lighting, or creator context.

## Ad sequence

### Opportunity alerts
- ددلاین نزدیک است — بورسیه بین‌المللی
- فرصت جدید — کارآموزی · ریموت
- برای تو مناسب است — فلوشیپ با تمویل کامل
- ذخیره شد — برای اقدام بعدی

### Brand / positioning
**ARIA HUB**

**پلتفرم هوشمند فرصت‌ها**

جستجو، تطبیق، ذخیره و اقدام — یک‌جا

### Audience
**برای مسیر تو ساخته شده**

از اولین جستجو تا اقدام نهایی

دانشجو · جوینده کار · فارغ‌التحصیل · پژوهشگر

### Automation
**اتوماسیون فرصت‌ها**

ARIA HUB مسیر را برایت مرتب می‌کند

- فرصت‌های مرتبط — تطبیق هوشمند
- ددلاین‌های نزدیک — هشدار
- فرصت‌های جدید — اعلان روزانه
- ذخیره‌شده‌ها — پیگیری

### Personalized matching
**فرصت‌های مرتبط را شخصی‌سازی می‌کند.**

بر اساس علاقه، سطح تحصیل، کشور و نوع فرصت.

### Dashboard proof
**همهٔ فرصت‌ها. یک سیستم.**

### Mobile alerts
فرصت جدید · ددلاین فردا · پیشنهاد برای تو
